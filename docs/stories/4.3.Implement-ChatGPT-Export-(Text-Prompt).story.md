### **User Story**

As a **user**, I want a **"Copy to ChatGPT" button that formats my query and relevant chunks into a ready-to-paste prompt**, so that **I can easily continue my analysis in an external LLM**.

### **Acceptance Criteria**

1.  A "Copy to ChatGPT" button is available on the search results screen.
2.  Clicking the button generates a text block containing the original query, a clear instruction for the LLM, and a numbered list of top N chunks with their metadata.
3.  The generated text block is automatically copied to the user's clipboard.
4.  A brief notification confirms that the content has been copied.

### **Dev Notes**

This is a client-side UI task. No backend services are required. The focus is on UI implementation within the existing PySide6 framework and data formatting.

*   **UI Component:** The "Copy to ChatGPT" button should be added to the `SearchView` widget. [Source: `docs/architecture/frontend-architecture.md`]
*   **File Location:** The primary files to be modified are likely:
    *   `src/zoterorag/ui/search_view.py`: To add the `QPushButton` and emit a new signal when it's clicked.
    *   `src/zoterorag/ui/main_window.py`: To connect to the new signal, implement the logic for formatting the text, and use `QApplication.clipboard()` to copy the text.
*   **Data Access:** The handler function in `main_window.py` will need access to the current search query and the list of `SearchResult` objects from the application's state. [Source: `docs/architecture/data-models.md`]
*   **Clipboard Interaction:** Use `QApplication.clipboard().setText(formatted_text)` to copy the generated prompt to the user's clipboard.
*   **Notification:** A simple `QMessageBox.information()` or a status bar message can be used to provide confirmation to the user. [Source: `docs/architecture/tech-stack.md`]
*   **Prompt Formatting:** The generated text should be structured clearly. Example format:

    ```text
    Based on the following research paper excerpts, please answer the query below.

    **Query:** "{user_query}"

    **Excerpts:**

    1.  **Source:** {document_title} ({authors}, {year}) - Page {page_number}
        **Content:** "{chunk_content}"

    2.  **Source:** {document_title} ({authors}, {year}) - Page {page_number}
        **Content:** "{chunk_content}"

    ...
    ```

### **Tasks / Subtasks**

1.  **(AC: 1)** In `src/zoterorag/ui/search_view.py`:
    *   Add a `QPushButton` with the label "Copy to ChatGPT".
    *   Define a new signal, e.g., `copy_to_chatgpt_requested = Signal()`.
    *   Connect the button's `clicked` signal to emit `copy_to_chatgpt_requested`.
2.  **(AC: 2, 3)** In `src/zoterorag/ui/main_window.py`:
    *   Connect the `search_view.copy_to_chatgpt_requested` signal to a new slot/handler method (e.g., `handle_copy_to_chatgpt`).
    *   Implement `handle_copy_to_chatgpt` to:
        *   Retrieve the current query and search results from the application state.
        *   Format the text string as specified in the Dev Notes.
        *   Use `QApplication.clipboard().setText()` to copy the string to the clipboard.
3.  **(AC: 4)** In `src/zoterorag/ui/main_window.py`:
    *   After setting the clipboard text, display a `QMessageBox` or update the status bar to inform the user that the prompt has been copied.
4.  **Testing:**
    *   Add a unit test to verify that the prompt text is formatted correctly based on sample data.
    *   Add a UI test (if feasible with `pytest-qt`) to simulate the button click and check the clipboard content.
