# Story 6.4: Implement Non-Modal Chunk Detail Dialog

### Status
Done

### Story
**As a** user,
**I want** to view the full text of a search result chunk in a larger, more readable format,
**so that** I can evaluate its relevance without having to open the full PDF.

### Acceptance Criteria
1.  **AC-6.4.1:** Double-clicking a chunk in the search results list opens a non-modal "Chunk Details" dialog.
2.  **AC-6.4.2:** The dialog displays the full, unabridged text of the selected chunk in a scrollable text area.
3.  **AC-6.4.3:** The dialog header shows the source document's title, and sub-headings show metadata like page number and relevance score.
4.  **AC-6.4.4:** The dialog includes "Previous" and "Next" buttons (and keyboard shortcuts `←`/`→`) to navigate through the list of result chunks without closing the dialog.
5.  **AC-6.4.5:** The dialog includes buttons to "Copy Text" and "Open PDF".

### Dev Notes
This story involves creating a new, non-modal UI component to display detailed information about a selected search result chunk.

#### **Component Specification**
*   **Component:** `ChunkDetailDialog`
*   **Class:** `ChunkDetailDialog(QDialog)`
*   **Behavior:** Must be non-modal (`Qt.NonModal`) to allow interaction with the main window while open.
*   **File Location:** Create the new component in `src/zoterorag/ui/chunk_detail_dialog.py`. [Source: `docs/architecture/frontend-architecture.md`]
*   **Instantiation:** The dialog should be instantiated and shown from the `SearchTab`'s `_on_chunk_double_click` event handler. A single instance should be created and reused. [Source: `docs/architecture/frontend-architecture.md`]

#### **Data Models**
*   The dialog will primarily display data from the `Chunk` and `Document` data models.
*   The `show_chunk(chunk: Chunk, all_chunks: list[Chunk])` method will be the main interface to update the dialog's content. [Source: `docs/architecture/components.md`]
*   The `Document` title and `pdf_file_path` will be retrieved via the `document_id` on the `Chunk` object. [Source: `docs/architecture/data-models.md`]

#### **UI Layout**
*   **Header:** A `QLabel` to display the `Document.title`.
*   **Sub-header:** `QLabel`s to display metadata (e.g., "Page: {chunk.page_number}", "Score: {search_result.score}").
*   **Content:** A `QTextEdit` set to be read-only and scrollable, displaying the full `Chunk.content`.
*   **Action Buttons:**
    *   `QPushButton("Copy Text")`: Copies the content of the `QTextEdit` to the clipboard.
    *   `QPushButton("Open PDF")`: Opens the `Document.pdf_file_path` using the system's default PDF viewer (e.g., using `QDesktopServices.openUrl`).
*   **Navigation Buttons:**
    *   `QPushButton("Previous")`: Navigates to the previous chunk in the list passed to the dialog.
    *   `QPushButton("Next")`: Navigates to the next chunk in the list.
    *   Keyboard shortcuts for left and right arrow keys should be connected to these navigation actions.

#### Testing
*   Create `tests/ui/test_chunk_detail_dialog.py`.
*   Write tests to verify that the dialog correctly displays chunk and document data.
*   Write tests to verify the functionality of the "Copy Text" and navigation buttons (mocking where necessary).
