# Story 1.2: Zotero Directory Detection & Selection

## Status
- Done

## Story
**As a** user,
**I want** the app to **automatically detect my Zotero data directory, or allow me to select it manually**,
**so that** the application can access my library.

## Acceptance Criteria
1.  1.2.1: On first launch, the application attempts to auto-detect the Zotero data directory.
2.  1.2.2: If auto-detection fails or is incorrect, the user is prompted to browse and select the directory.
3.  1.2.3: The selected Zotero directory path is persisted across application launches.
4.  1.2.4: The application displays a clear message indicating whether a valid Zotero directory is configured.

## Dev Notes

### Previous Story Insights
- Story 1.1 established the basic PySide6 `MainWindow` and project structure. This story will build on that by adding the initial application logic for setup.

### Architecture & Technical Details
- **Workflow:** This story implements the first part of the "Initial Setup & Indexing Workflow". [Source: `docs/architecture/core-workflows.md`]
- **Component Interaction:**
    - The `MainWindow` will use a `QStackedWidget` to show either the `OnboardingView` or the main `SearchView`. [Source: `docs/architecture/frontend-architecture.md#route-organization`]
    - On startup, `MainWindow` will query the `SettingsManager` for the Zotero path.
    - If the path is missing, the `OnboardingView` will be shown.
    - The `OnboardingView` will use the `ZoteroManager` to attempt auto-detection.
    - If auto-detection fails, the user will be prompted to select a directory using a `QFileDialog`.
    - The selected path will be saved using the `SettingsManager`.
- **Key Components:**
    - `SettingsManager`: Responsible for persisting the `zotero_data_path`. The implementation should handle loading from and saving to a local configuration file. [Source: `docs/architecture/components.md#settingsmanager`]
    - `ZoteroManager`: Implements the `detect_zotero_directory()` method. This should contain logic to check default Zotero installation paths for different operating systems (macOS, Windows, Linux). [Source: `docs/architecture/components.md#zoteromanager`]
    - `OnboardingView`: A new UI component to be created. It will contain a label to show the detected path (or status) and a button to manually select a directory. [Source: `docs/architecture/frontend-architecture.md#component-organization`]
- **File Locations:**
    - `SettingsManager` logic: `src/zoterorag/config/settings_manager.py`
    - `ZoteroManager` logic: `src/zoterorag/core/services/zotero_manager.py` (Create if not exists)
    - New UI View: `src/zoterorag/ui/onboarding_view.py`
    - `MainWindow` modifications: `src/zoterorag/ui/main_window.py`
- **Testing Requirements:**
    - Unit tests should be created for the `detect_zotero_directory()` function in `ZoteroManager` to mock different OS environments and check for correct default paths.
    - Unit tests for `SettingsManager` should verify that the path is correctly saved and loaded.
    - Manual testing should verify the full UI flow as described in the ACs. [Source: `docs/architecture/tech-stack.md`]
