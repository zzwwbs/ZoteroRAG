# Story 8.4: Remove Auto-Tab-Switch & Default to Search Tab

## Status
- **Done**

## Story
**As a** user,
**I want** to stay on the Index tab after indexing completes and have the app open to the Search tab by default,
**so that** I can review the indexing results immediately and my primary activity is readily available on startup.

## Acceptance Criteria
1.  **Remove Auto-Switch After Indexing**
    - After indexing completes, the user remains on the Index tab.
    - There is no automatic switch to the Search tab or any other tab.
    - The user can still manually switch tabs if desired.

2.  **Default Tab on Startup**
    - The application opens to the Search tab on launch.
    - This default tab setting applies to all users and is not configurable in the MVP.

3.  **Manual Tab Switching Preserved**
    - The user can switch tabs at any time (before, during, or after indexing).
    - Tab switching via clicks or keyboard shortcuts works normally.

4.  **State Consistency**
    - The active tab state is preserved if the user manually switches away from the Index tab during indexing.
    - The completion of indexing does not override the user's current tab choice.
