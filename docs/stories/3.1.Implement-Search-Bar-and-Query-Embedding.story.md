## User Story

As a **user**,
I want **a search bar where I can type my question**,
so that **I can initiate a semantic search**.

## Acceptance Criteria

*   **3.1.1:** The main UI includes a prominent text input field for search queries.
*   **3.1.2:** When a user executes a search, the application sends the query text to the configured cloud embedding API.
*   **3.1.3:** The application receives the resulting query embedding vector.
*   **3.1.4:** The UI indicates that a search is in progress.

### Component Specifications
*   The main UI is the `ZoteroRAG Desk Application (Main UI)`. (Source: `architecture/components.md`)
*   A `SearchView` widget will contain the search bar (`QLineEdit`) and a search button (`QPushButton`). It will emit a `search_triggered` signal with the query string when the user initiates a search. (Source: `architecture/frontend-architecture.md#Component Architecture`)
*   The `MainWindow` will manage the `SearchView` and connect its `search_triggered` signal to an `on_search` slot. (Source: `architecture/frontend-architecture.md#Frontend Services Layer`)
*   The `MainWindow` will utilize `QThreadPool` and `QRunnable` for executing background tasks (like API calls) to maintain UI responsiveness. (Source: `architecture/frontend-architecture.md#Frontend Services Layer`)
*   The `SearchService` component is responsible for processing natural language search queries, including generating embeddings. (Source: `architecture/components.md#SearchService`)
*   The `EmbeddingClient` component handles communication with the external OpenAI-compatible API to generate vector embeddings for text. (Source: `architecture/components.md#EmbeddingClient`)
*   The `SettingsManager` is a dependency for `EmbeddingClient` to retrieve the user-provided API key. (Source: `architecture/components.md#EmbeddingClient`)

### File Locations
*   `src/ui/search_view.py`: For the `SearchView` widget. (Source: `architecture/frontend-architecture.md#Component Organization`, `architecture/unified-project-structure.md`)
*   `src/ui/main_window.py`: For the `MainWindow` logic, including handling search initiation and UI updates. (Source: `architecture/frontend-architecture.md#Component Organization`, `architecture/unified-project-structure.md`)
*   `src/core/services/search_service.py`: For the `SearchService` implementation. (Source: `architecture/unified-project-structure.md`)
*   `src/core/services/embedding_client.py`: For the `EmbeddingClient` implementation. (Source: `architecture/unified-project-structure.md`)
*   `src/config/settings_manager.py`: For the `SettingsManager` implementation. (Source: `architecture/unified-project-structure.md`)

### API Specifications
*   The `EmbeddingClient` will make API calls to the OpenAI-compatible API (e.g., `POST /v1/embeddings`). (Source: `architecture/core-workflows.md#Initial Setup & Indexing Workflow`, `architecture/components.md#EmbeddingClient`)
*   API authentication for embedding generation will use a user-provided key obtained via the `SettingsManager`. (Source: `architecture/components.md#EmbeddingClient`)

### Technical Constraints
*   Long-running operations, such as API calls for embedding generation, must be executed in background threads using `QThreadPool` and `QRunnable` to prevent the UI from freezing. (Source: `architecture/coding-standards.md#Threading`, `architecture/frontend-architecture.md#Frontend Services Layer`)
*   All UI updates must be performed exclusively from the main GUI thread. (Source: `architecture/coding-standards.md#Threading`)
*   Robust error handling should be implemented for API interactions, covering network errors, invalid API keys, and rate limiting. (Source: `docs/prd/6-epic-details.md#Story 2.3: Implement Cloud Embedding Generation` - *general API interaction constraint*)

### Accessibility & Responsiveness
*   The implementation must adhere to WCAG 2.1 AA standards as specified in `architecture/frontend-architecture.md`.
*   The `SearchView` and its components must be fully keyboard accessible, including triggering a search via the Enter key.
*   Clear visual focus indicators must be present on the search bar and button.

*   **Integration Tests:**
