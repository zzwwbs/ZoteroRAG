## Dev Notes

### Technical Context
- **Target Component:** The primary changes will be in `src/zoterorag/core/services/indexing_service.py`, which is responsible for the core logic of processing and indexing documents. [Source: `docs/architecture/unified-project-structure.md`]
- **Dependency Management:** The project uses `pyproject.toml` for dependency management. The `PyMuPDF` library should be replaced with `pdfplumber`. [Source: `docs/architecture/tech-stack.md`]
- **Logging:** The application uses the standard Python `logging` module. Errors should be logged appropriately to the application's log file. [Source: `docs/architecture/tech-stack.md`]

### Data Models
- The extraction process feeds into the `IndexingService`, which creates `Document` and `Chunk` objects. The extracted text is used to create `Chunk`s. The format of the extracted text must remain a simple string to ensure compatibility with the chunking utility. [Source: `docs/architecture/data-models.md`]

### File Locations

- **Tests:** `tests/core/test_indexing_service.py`
- **Dependencies:** `pyproject.toml`

  ```python
      text_parts = []
      for page in document.pages:
          text = page.extract_text() or ""
          text = text.strip()
          if text:
              text_parts.append(text)
      return "\n".join(text_parts)
  ```
